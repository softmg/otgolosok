## Проверка

Dry-run, резервная копия SQLite и проверка отсутствия конкурирующих правок выполнены. Шесть задач F5 завершились с первой попытки. Свежий состав промопрогулок не содержит этих ID. По публичному HTTPS проверены тексты, контрольные суммы шести MP3 и оба размера четырёх превью. Фото внесены в постоянный каталог и стандартный источник сборки; развёртывание выполнено при отсутствии активных задач озвучки.

Пройдены lint, typecheck, Vitest (117 файлов, 1484 теста), backend (810), Ruff, Pyright, pytest (26 тестов, 78 subtests). Всего опубликовано и переозвучено 100 из 400 кандидатов, ещё четыре проверены без правки. Подробности: [changes.json](./changes.json), [publication.json](./publication.json).
