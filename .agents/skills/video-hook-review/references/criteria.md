## Примеры слабых решений

Таблица помогает распознать проблему при применении правил выше; это учебные примеры.

| Предмет проверки | Слабое решение |
|---|---|
| Аудитория | Автору интересна редкая фамилия, зрителю неизвестно, что произошло |
| Узнаваемая опора | Зрителю сначала нужно выучить три имени и архитектурный термин |
| Нарушение ожидания | Контраст придуман автором; обычная перестройка названа невероятной |
| Значимость | Историческая редкость без понятной причины интересоваться |
| Предмет любопытства | «Узнайте удивительную историю», «здесь есть тайна» |
| Неочевидность ответа | «Почему пришлось ремонтировать?» — «потому что сломалось» |
| Сильнейший факт | Вход начинается с адреса, а «единственный открытый храм» вырезан |
| Достаточность материала | Две соседние справки объявлены причинной историей |
| Новизна | Другое здание автоматически считается другой темой |
| Конкретность | «Как изменилась роль этого уникального объекта?» |
| Точка входа | Экспозиция о строительстве прежде события, ради которого выбрали сюжет |
| Устная ясность | Проговаривание года и дроби занимает первые секунды, а событие ещё не названо |
| Термины | «Фермы», «апсида», «хиротония» без опоры для неподготовленного зрителя |
| Указатели | Голос обещает узнать о троих, а на изображении только фасад |
| Переход к развитию | Повтор хука другими словами и возврат к музейной справке |
| Выполнимое обещание | Вопрос про спящих в кроватях, ответ только про работающий водопровод |
| Новое понимание | Развязка дословно повторяет начало; весь ответ уже исчерпан |
| Привлекательность визуала вместе с речью | Вместо основного визуала — скрин текста, страницы или цитаты; зрителю предлагают прочитать справку |
| Первый кадр | Скучный общий план или случайная красивая картинка без связи с историей |
| Доказательство | Фото того же места выдано за снимок описанного события |
| Речь и изображение | Голос говорит про шпиль, кадр показывает только стену снизу |
| Экранная фраза | Первые слова собираются по одному, интрига видна лишь к третьей секунде |
| Зрительная нагрузка | Два дублирующих заголовка и субтитры поверх документа |
| Движение и звук | Частые склейки, громкий акцент или приближение без новой информации |
| Упаковка | На обложке убийство, в ролике только адрес дома |
| Честность реконструкции | ИИ-сцена, подмена даты или перспектива создают ложное доказательство |

## Разбор фактических подмен

Примеры различий:

- «Единственный открытый католический храм **Москвы с 1938 года**» не равно «единственный храм СССР» или «единственный католический храм России».
- Тайные посвящения в 1926 году и сохранение открытого храма позднее не доказывают, что храм сохранили **из-за** посвящений.
- Перенос здания с жильцами не доказывает, что все жильцы спали, лежали в кроватях или ничего не заметили.
- «Колокольня утрачена» и наличие дыма на снимке не доказывают взрыв, его дату или виновника.
- Наклонная вертикаль в перспективном снимке не равна измерению реального наклона.


## Исторические ориентиры

«До 12 слов», 25–80/90 символов, 2–4 слова обложки и 3–5 слов титра происходят из разных артефактов и версий конвейера. Их применение определяют EDIT-05 и PACK-01 выше. Окно 2–3 с для проверки понимания, учебный вопрос до 10 с для семейного фильма и 10–30 с для длинного документального формата также относятся к разным условиям.

## Работа с аналитикой

Интерпретация метрик — [EDIT-04](../../../../../otgolosok-shorts/assets/promo-review/editorial.md#edit-04), процедура зрительской проверки и ограничения данных — EDIT-05 выше. В отчёте удобно сопоставить долю «остались смотреть / пролистали» в Studio с кривой первых секунд и отдельно записать общий контекст: просмотры, средний процент просмотра и комментарии.
