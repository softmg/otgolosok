# Локальная история создания роликов

## Запуск

Из корня `otgolosok`:

```sh
pnpm video:observe
```

Откройте `http://127.0.0.1:4317`. Для другого расположения исходных данных или
занятого порта:

```sh
pnpm video:observe --root /путь/к/otgolosok-creative --port 4318
```

Инструмент читает локальный `data/daily` соседнего `otgolosok-creative`.
Новые даты появляются после обновления списка; выбранный запуск обновляется
автоматически каждые 15 секунд, пока вкладка видна. Ключи и `.env` не нужны.
Сервер слушает только loopback; для просмотра из удалённого BB используйте
`bb connect expose 4317` и полученную ссылку. Завершение — `Ctrl+C`; после
остановки удалите проброс командой `bb connect unexpose 4317`.

## Что показывает страница

Слева находятся локальные выпуски. Внутри каждого — последнее записанное
состояние, последовательность этапов, измеренные длительности, история
событий, ремонтные попытки, повторные отказы проверок и основания выводов.
Фильтры помогают выделить ошибки, редакцию, рендер или конкретный этап.
Время показывается в часовом поясе браузера.

Это реконструкция сохранённых свидетельств. Инструмент не проверяет процессы
исполнителей и не опрашивает YouTube. Возраст наблюдения важен: старое
`running` и отсутствие результата ремонта не подтверждают работу процесса.
Квитанция публикации описывает состояние на момент её записи. Исторические
отказы не должны превращать подтверждённо опубликованный выпуск в текущую
ошибку. Ожидание между событиями не считается временем рендера.

Отчёт различает подтверждённые результаты, гипотезы и неизвестное. Повторы с
одинаковой проблемой и входами — сильный признак отсутствия прогресса.
Одинаковый код ошибки без отпечатков входов требует проверки. Изменение файла
ещё не означает, что профильная проверка приняла правку.

Много отказов редакции само по себе не доказывает избыточную строгость.
Подсказки предлагают проверить доступность доказательств на нужной фазе,
противоречия замечаний и повторные проверки неизменённых материалов.
Требования к фактам, лицензиям, звуку и финальному файлу сохраняются.

## Разбор с ИИ

Кнопка копирования формирует задание с данными и ссылками на локальные
свидетельства. JSON содержит нормализованные события, ремонты, группы
повторов и локальные подсказки; Markdown — готовый читаемый разбор и пакет
для ИИ. Внешняя модель автоматически не вызывается. Передайте пакет агенту
и попросите проверить гипотезы по указанным файлам, сравнить соседние выпуски
и предложить проверяемые улучшения.

Экспорт без сервера:

```sh
pnpm video:observe --run 2026-11-13 --export artifacts/video-observer
```

Локальные отчёты в `artifacts/` исключены из Git. Источники не изменяются:
инструмент не запускает рендер, ремонт, переозвучку или публикацию.

## Границы и проверка

Адаптер читает только известные файлы, ограничивает объём и число записей,
показывает предупреждения при неполных или повреждённых данных. Переходы по
символическим ссылкам за пределы источника запрещены. Свободный текст
очищается от типичных секретов; необработанные журналы и промпты исполнителей
через HTTP не выдаются.

Тесты находятся в `backend/video-observer-*.test.mjs` и входят в штатную
команду Node-тестов. Они проверяют происхождение статусов, неполные данные,
повторы, разделение инфраструктуры и редакции, границы HTTP и экспорт.
Интерфейс не включён в production-приложение и статический экспорт Next.js.
