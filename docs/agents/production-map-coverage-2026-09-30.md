# Полнота точек на production-карте

Проверено 30 сентября 2026 года на https://otgolosok.online/. Проверка production выполнялась только чтением: SQLite открыт с `readOnly: true`, публичные запросы — GET, браузер — новая гостевая сессия без геолокации. Код приложения и production-данные не менялись.

## Результат

- В production-базе 1 460 неархивных мест с утверждённым текстом. У 1 438 есть аудио, у 22 — только текст; число 1 438 соответствует озвученным местам.
- Публичный `/api/content/places?limit=100&offset=…&status=ready` постранично возвращает все 1 460 уникальных мест, включая 1 438 с аудио. У всех записей числовые координаты.
- При открытии главной страницы браузер делает единственный запрос `/api/content/places?limit=100&status=ready`. Ответ: `total: 1460`, `places.length: 100`, `hasMore: true`; аудио есть у 99 записей этой страницы.
- В DOM карты 105 маркеров: 100 записей каталога, четыре главы встроенной прогулки и Дом Мельникова. Ошибок JavaScript при этой проверке не было.

## Причина и исправление

`src/features/explore/around-screen.tsx` запрашивает одну страницу с `limit=100`, сохраняет только `value.places` и не обрабатывает `hasMore` и `offset`. Поэтому 1 360 утверждённых записей каталога не попадают в начальный набор маркеров. При выборе центра радиус ограничивается 5 км, но предел в 100 записей остаётся. Перемещение и масштабирование карты сами по себе не запускают догрузку каталога.

Нужно реализовать полную загрузку маркеров с обработкой страниц, отмены и ошибок либо отдельную компактную выдачу маркеров по видимой области с гарантией полноты. Простое увеличение `limit` на клиенте не исправит проблему: сервер допускает максимум 100 записей на страницу. Для текущего каталога достаточно корректной пагинации; регрессионная проверка должна охватывать более 100 мест и сбой промежуточной страницы. Исправление в рамках этой проверки не выполнялось.

## Проверки перед сохранением заметки

ESLint прошёл; отдельный `pnpm test` завершился успешно: 404 frontend-теста и 489 backend-тестов. Общий `pnpm check` остановился на TypeScript: параллельно добавляемый `src/features/explore/place-photo.tsx` импортировал ещё отсутствующий `content/place-images.json`. Эти изменения не относятся к проверке карты и не включены в коммит заметки; полный цикл проверки и сборки поэтому не подтверждён.
