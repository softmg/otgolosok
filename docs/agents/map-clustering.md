# Группировка мест на карте

Каталог объединяется в группы с количеством через [Leaflet.markercluster](https://github.com/Leaflet/Leaflet.markercluster). Радиус группы — 52 экранных пикселя: при приближении точки расходятся, нажатие или Enter приближает группу. Совпадающие координаты раскрываются веером, поэтому каждая история остаётся доступной.

Выбранное место, готовящаяся история и пронумерованные остановки прогулки находятся в отдельном слое. Фоновые точки при создании прогулки группируются. Обновление страниц каталога добавляет только новые маркеры пакетами, удаление проходит через соответствующий слой. Координаты сравниваются с исходными данными: временное смещение маркера при раскрытии веером не должно сбрасываться при повторном рендере React.

Плагин загружается после Leaflet только в браузере. Он расширяет исходный CommonJS-объект, поэтому используется default-export Leaflet, а не неизменяемое пространство имён динамического импорта. Анимация групп отключена в соответствии с мгновенным масштабированием карты; это исключает отложенные анимационные обращения к карте после ухода с экрана.

Группы имеют область нажатия 48×48, число мест и доступное имя с действием. Объекты за пределами расширенной видимой области исключаются из DOM средствами плагина. Полный каталог по-прежнему загружается постранично со статусом и повтором после ошибки: эта оптимизация сокращает число рисуемых элементов, объём ответа API не меняется.

## Проверка

На 1 438 тестовых местах сумма чисел в группах и отдельных маркеров равна 1 438, при исходном масштабе DOM содержит меньше 30 маркеров. Проверены догрузка страниц, изменение координат, удаление мест, выделение, пустой каталог и восстановление после HTTP 503. Отдельные браузерные сценарии проверяют Enter, повторное объединение при отдалении, раскрытие совпадающих координат и открытие карточки.

На production-сборке локально прошли 69 браузерных сценариев карты, интерфейса и прогулок. Скриншоты групп и раскрытых точек просмотрены. Полная проверка `pnpm check` включает линтеры, типы, frontend/backend/Python-тесты и статическую сборку. Production в рамках этой правки не обновлялся.
