# План: новые промопрогулки из готовых точек

Status: plan, 2026-10-16. Этап 0 (отбор кандидатов) выполнен; выбор вариантов за пользователем.

> Снимок на 16 октября 2026 года, `main` (`ac473f1`). Перед каждым этапом заново снимать production скиллом `promo-walk-candidates`: точки, промопрогулки и очередь меняют параллельные сессии.

## Цель и критерии

Собрать следующие промопрогулки из точек, у которых на production уже есть одобренный рассказ и аудио:

- не меньше 10 остановок, не больше 20;
- не меньше 18 минут **измеренного** финального аудио v4, ориентир запас от 60 секунд;
- общих точек с каждой существующей промопрогулкой не больше 50 % от точек новой; варианты не пересекаются между собой больше чем на 50 %;
- пешая связность: путь до ~4 км, соседние остановки не дальше ~700 м, начало и конец у метро;
- слушатель стоит у объекта снаружи: без билетных территорий и закрытых дворов;
- рассказы без инициалов и канцелярских адресных справок (скиллы `remove-initials`, `remove-reference-addresses`);
- озвучка только ElevenLabs v4 (`provider: elevenlabs`, `model: eleven_v4`), голос «Отголосок2»; F5 и v3 заменяются, прежний звук доступен до готовности замены.

## Этап 0. Отбор (выполнен 16.10)

Скилл `promo-walk-candidates` (`.claude/skills/promo-walk-candidates/`): read-only снимок 41 промопрогулки аккаунта `promo-walks` и 2105 озвученных точек, автоматический перебор районов, затем ручной отсев шума (бизнес-центры, министерства, отели, доски, посольства). Длительность записей F5 и v3 оценена по числу слов (темп v4 ~117 слов в минуту), точной она станет только после переозвучки.

## Этап 1. Выбор и состав

1. Пользователь выбирает варианты первой очереди.
2. По каждому — точный список точек с id из свежего снимка, порядок, старт и финиш у выхода метро. Названия прогулок в формате «Остоженка: искусство и частная жизнь».
3. Пересчитать пересечение с актуальными промопрогулками и между выбранными вариантами.

## Этап 2. Проверка на месте и маршрут

1. Пешие пути через Valhalla (`/sources_to_targets`, затем `/route`): нет магистралей без перехода, промзон, закрытых дворов.
2. Доступ: часы работы Новодевичьего монастыря и парка Царицыно, точки прослушивания у входа или у ограды; в описании прогулки указать часы, если территория закрывается.
3. Точки внутри зданий (музеи, бани) слушаются у фасада: проверить, что текст не требует входа.

## Этап 3. Редакция текстов

1. Прочитать актуальные одобренные рассказы всех точек (не исторические пакеты из `content/`).
2. Убрать инициалы и адресные справки скиллами; рассказы короче 100 слов дополнить проверенными фактами.
3. Проверить фото (лицензия, тот ли объект); недостающие — с Commons.
4. Изменённый текст переозвучивается целиком: старый MP3 этой карточки в сумму не входит.

## Этап 4. Переозвучка v4 (платно)

1. Перед партией назвать пользователю точный список точек, число символов и аккаунт ElevenLabs; запуск только после подтверждения.
2. Замены через штатную очередь с явными стабильными UUID переозвучки, как в `docs/agents/promo-f5-to-v4-2026-10-07.md`; повтор не должен запускать повторный синтез.
3. После готовности: `provider`, `model`, `voice` каждой записи прочитаны из опубликованного артефакта; MP3 скачан, длительность через ffprobe; сумма по прогулке от 18 минут. Если не хватает — добавить точку или дополнить рассказ и измерить снова.

## Этап 5. Создание и публикация

1. Прогулка создаётся через служебный API промопрогулок (`docs/agents/promo-walks-service-api.md`) с ручными остановками; пробный прогон `dryRun` до записи.
2. Мобильная проверка в Chrome: все остановки, тексты, воспроизведение каждой записи, линия маршрута.
3. Постановка в очередь промо по текущему расписанию (`docs/agents/promo-schedule-2026-10-14.md`) — по команде пользователя.
4. Промо-набор (Shorts, Telegram, обложки) — скиллом `walk-promo`, публикация только по явной команде.

## Покупки izi travel

Для вариантов 1–9 не нужны: прогулки собираются из уже опубликованных рассказов, расход — только переозвучка v4. Материалы izi понадобятся, лишь если дописывать отсеянные районы (Девичье поле, Коломенское, Пресня): сначала бесплатные туры из `content/izi-free-moscow-2026-10-02/tours.json` и открытые источники; платный тур — только если по району нет бесплатного материала, и по согласованию. Тексты туров не копируются: факты подтверждаются независимыми источниками, рассказ пишется заново.
