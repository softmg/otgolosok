# Создание прогулки на карте

Реализовано 22 сентября 2026 в `feat/auth-account-osm-pipeline`.

## Навигация и данные

`/?walk=create` открывает немодальную панель на существующем Leaflet. Параметры
`local`/`id` выбирают редактируемый документ; `resume=1` продолжает черновик.
Старые `/walk?new=1`, `resume`, координаты и `edit=1` перенаправляются сюда;
`/walk` без параметров ведёт в `/history`. Просмотр `local/id/catalog/share`
сохраняется на `/walk`. Конфликтующие намерения отвергаются до восстановления.

Вход от дома подтверждает старт. Новый вход открывает чистую форму из двух полей, сохраняя предыдущий документ
в истории. Адрес, карта и время выбираются через раскрываемое поле. Закрытие не удаляет черновик.
Ключи `otgolosok:walk:active-local`, `active-account`, `active-revision` связывают
активный v1-черновик с документом. Локальная запись использует revision; после
сохранения в аккаунт несохранённые изменения остаются в v1 и восстанавливаются
только при совпадении серверной revision. При конфликте доступно скачивание.
Recovery token, ID исследования и неизвестный результат отправки сохраняются;
восстановление выполняет GET, а не повторный заказ.

`destination` проходит через planner, исследование, документ v2 и проигрыватель.
Сначала проверяется достижимость финиша, затем подбираются необязательные остановки.
Истории генерируются для исторических остановок. Бюджет 30/60/90 означает ходьбу,
без времени прослушивания. Для режима по времени возврат включён по умолчанию.
Backend с поддержкой поля необходимо выпустить перед новым клиентом.

История использует summary-поля аккаунтного списка и курсорную пагинацию без
загрузки полного документа каждой карточки. Сортируются загруженные записи;
доступная следующая страница обозначена кнопкой. Избранное получает только
безопасные названия/ссылки; недоступные объекты не раскрывают содержимое.

## Проверки

- `pnpm lint`, `pnpm typecheck`, `pnpm test`: 264 клиентских и 228 серверных тестов.
- `pnpm test:e2e`: 18 сценариев Chromium, включая A→Б, дом→старт, Back/forward,
  Escape/focus, восстановление исследования без POST, аккаунтный черновик,
  пагинацию, независимый отказ раздела профиля и выход при недоступном сервере.
- Размеры: 360×800, 390×844, 568×400, 844×390, 699×800, 700×800, 768×1024,
  1440×900. Проверена геометрия панели/навигации; сняты и просмотрены скриншоты
  панели, истории и профиля. Артефакты находятся в игнорируемом `test-results/`.
- `pnpm build`: статический `/history` и manifest service worker сформированы.
  Алиасы `/history`, `/history/`, `/history.html` учитываются офлайн-оболочкой.

API в E2E заменены фикстурами, реальные платные исследования не запускались.
Внешний router, production-авторизация, iOS-клавиатура и аппаратный safe-area
на устройстве в этой проверке не проверялись; это не свидетельство деплоя.
Локальная Node 24.18.0 ниже требования проекта >=24.20.0: команды прошли,
но перед выпуском следует повторить CI на поддерживаемой версии.

Существующие чужие изменения стилей офлайн-кнопки, карты и геолокационного маркера
сохранены вне коммитов этой реализации.

Адрес вводится внутри поля «Откуда»/«Куда». Enter или кнопка «Подтвердить адрес»
выполняет явный поиск через `/api/story-place`; найденная точка сразу записывается
в маршрут. При ошибке текст остаётся в поле. Подсказки по каталогу отключены:
каталог историй может быть пустым и не является адресным реестром Москвы.
