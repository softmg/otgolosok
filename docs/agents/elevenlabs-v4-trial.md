# Пробная озвучка ElevenLabs v4

5 октября 2026 года два рассказа промопрогулки от «Спартака» («Станция метро „Спартак“», 1776 символов с тегами, и «Памятник жертвам теракта 5 июля 2003 года», 874 символа) озвучили голосом «Отголосок2» тремя моделями: `eleven_v3`, `eleven_v4` и `eleven_v4_turbo`. Теги расставлены вручную по правилам `audioTagsPrompt` и прошли `validateTaggedNarration`; запрос такой же, как у бэкенда (`language_code: "ru"`, `mp3_44100_128`).

- Ключ принимает все три идентификатора модели; `eleven_v4_turbo` существует и отвечает с тем же голосом.
- Заголовок `character-cost` (по запросам «Спартак» / «Крылья»): v3 — 781 / 385, v4 — 215 / 106, v4 Turbo — 107 / 53. Счётчик подписки за весь прогон вырос на 3367, и с суммой заголовков (1647) это не сходится. Перед массовой переозвучкой проверьте расход по счётчику подписки на одном рассказе.
- Длительность почти одинаковая: «Спартак» 1:51 у всех трёх, «Крылья» 0:59 у v3 и 0:55–0:56 у v4.
- Время ответа на весь текст у всех моделей 13–35 с. Без потокового режима Turbo по скорости не выигрывает (потоковый режим не проверяли).

## Локальный Node 25 ломает fetch

На Node 25.8.1 после `import "undici"` (8.11.0; его подключает `backend/provider.mjs`) глобальный `fetch` возвращает ответы без заголовков. Из-за этого `createElevenLabsTts` локально всегда падает с `TTS_FAILED` на проверке `content-type`. Прод и Docker работают на Node 24.20 (`engines` в `package.json`), там ошибки нет. Локальные проверки озвучки запускайте на Node 24.

## Переход production на eleven_v4 (5 октября 2026)

Коммит `0dc2324` сделал `eleven_v4` моделью по умолчанию и добавил модель в параметры профиля `elevenlabs-v3`. Без этого повторная постановка уже озвученного текста возвращала завершённое задание v3, а не синтезировала заново. В `.generator.env` на сервере модель тоже переключена на `eleven_v4`, рядом лежит резервная копия с `eleven_v3`. Пока шла выкладка, другой агент поменял скрипт выкладки в репозитории services, и bash упал на последней строке. Контейнер к этому моменту уже был обновлён, поэтому проверку TLS запустили вручную.

Пользователь просил переозвучить на v4 только две точки прогулки от «Спартака»: станцию «Спартак» и памятный знак жертвам теракта на «Крыльях». Я ошибочно поставил в очередь все 113 текущих текстов с озвучкой v3 и через несколько минут отменил 108 из них (`state='cancelled'`; список в `/data/ops-backups/elevenlabs-v4-2026-10-05/cancelled.json`, вернуть отдельное задание можно через `retryExternalAudio`). Пять точек успели получить v4, по решению пользователя они остаются на v4: дом Павлова, памятник Шолохову, «Вдохновение», Хитровка и знак у «Крыльев». Станция «Спартак» озвучена отдельно (1:52). Остальные записи v3 не тронуты.
