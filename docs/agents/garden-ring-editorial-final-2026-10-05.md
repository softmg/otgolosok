# Завершение редакторской проверки Садового кольца

Обработаны все 400 выбранных production-точек: 396 рассказов опубликованы и переозвучены, четыре проверены без повторной правки. [Итоговый отчёт](../../content/garden-ring-intros-2026-10-03/final-report.md) содержит список точек без подтверждённого превью, публичную проверку и сопоставление каждого MP3 с исходным текстом.

Все 25 точек в 13 промопрогулках используют ElevenLabs. Полная проверка выявила более свежую запись дома Павлова относительно раннего отчёта партии: успешное задание подтвердило хеш нынешнего текста, а публичная глава отдала этот же MP3. В API промопрогулки аудио содержит URL, SHA-256 и длительность; модель проверяется по карточке точки, а совпадение файла — по SHA-256.

Для двух старых изображений, доски 9-й дивизии ополчения и портрета Гулевича, Commons подтвердил Public domain. Ссылка на общий шаблон PD-ineligible заменена ссылкой на раздел лицензирования конкретного файла, без замены самих изображений.

## Доставка фотографий

Во время работы параллельная публикация frontend удалила из dist ещё не закоммиченные изображения партии 49. Файлы восстановлены, партия зафиксирована; итоговая проверка всех доступных фотографий прошла без 404. Подробности сохранены в [отчёте партии 49](../../content/garden-ring-intros-2026-10-05-batch49/README.md).

Риск повторения связан с тем, что generator-каталог и публичные файлы обновляются отдельно, а frontend-сборка берёт только HEAD. Правильное дальнейшее исправление: исключить постоянные изображения из разрушительной замены dist либо публиковать каталог и весь набор медиа атомарно из зафиксированной версии. Новая инфраструктура в рамках редакторской работы не добавлялась.

## Метаданные картографических точек

Текст рассказа и подпись фотографии могут содержать проверенный адрес при устаревшем адресе или названии в исходных метаданных OSM. Например, городской каталог указывает для доски Токареву Большую Полянку, 7/10, строение 1; прежний текст ссылался на 3/9. У сквера Плисецкой проверено официальное переименование 2025 года в сквер Майи Плисецкой и Родиона Щедрина, тогда как имя исходной точки осталось прежним.

Для системного исправления таких метаданных нужен поддерживаемый слой редакторских уточнений, который сохраняется при повторном импорте OSM. Разовый SQL-update или importPlaces без устойчивого источника исправлений будет перезаписан следующей синхронизацией. Рассказам и превью в этой работе присвоены проверенные адреса и ясные подписи; массовые изменения координат не выполнялись.

## Проверка источников

Нельзя устанавливать идентичность по ближайшей карточке Wikimapia. Особенно это важно для досок, скульптур в парке и нескольких корпусов одной усадьбы. У доски театру «Скатуве» совпадение координат снимка с исходной точкой подтвердилось; соседний адрес по Большой Дмитровке сам по себе не доказывает ошибку координат.

В собственном музейном каталоге «Философский камень» указан как серый гранит, а не чёрный. Карточка «Адамова яблока» Балашова относится к другому произведению и не использована для «Яблока» Калугиной. Для последнего сохранилась атрибуция исходному городскому перечню; независимая новая музейная карточка не найдена.
