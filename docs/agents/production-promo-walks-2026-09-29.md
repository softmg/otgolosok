# Подготовка обновления промо-прогулок 29 сентября 2026 года

В `origin/main` появился `1827700` (PR #7), но production уже содержал
локальные изменения админки, отсутствующие в GitHub. После нормализации
CRLF все JavaScript-модули production-backend совпали с `433c853`.
Для выкладки подготовлена отдельная detached-копия: `433c853` плюс merge
`1827700`. Незавершённые правки основного рабочего каталога в неё не входят.
Фронтенд не требует повторной публикации: PR меняет только backend.

В чистой копии перед `pnpm check` нужны `pnpm exec next typegen` и
`node scripts/build-walk-catalog.mjs`. Без первого шага TypeScript не видит
`LayoutProps`; без второго тест каталога сравнивает LF-генерацию с CRLF
рабочей копии. Содержимое каталога после генерации не меняется по git diff.
Постоянное исправление: включить генерацию в подготовку проверок и закрепить
LF для генерируемого каталога; в рамках этой выкладки код проверок не менялся.

Штатный deploy-скрипт проверяет активность `jobs`, но не `content_jobs`.
Остановка обработчика текста может завершить текущую попытку как `TIMEOUT`.
Перед переключением нужно приостановить работающие партии, дождаться
окончания текущего задания и восстановить прежние состояния после выкладки.
Постоянное исправление описано также в
[заметке о параллельных выкладках](production-deploy-concurrency.md).
