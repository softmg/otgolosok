# Адресные вводные абзацы внутри Садового кольца

3 октября 2026 года по просьбе пользователя собран широкий список описаний,
где первые предложения посвящены местоположению. Точное совпадение с фразой
«Эта точка располагается по адресу» не подходит для отбора: примеры пользователя
начинаются с названия объекта, улицы или определения музея, а адрес появляется
в следующем предложении. Наличие адреса само по себе не считается дефектом.

Результат находится в
[content/garden-ring-intros-2026-10-03/README.md](../../content/garden-ring-intros-2026-10-03/README.md).
Это 400 кандидатов, 18 точек для проверки границы и 14 пробных полных редакторских
вариантов. Семь вариантов обогащены сведениями Wikimapia; остальные используют
исходные факты или первичный источник при расхождении. После явного одобрения пользователя все 14 вариантов опубликованы на production
с новой озвучкой F5; пять точек получили превью. Остальные 386 кандидатов не менялись.

## Методика

Production-снимок получен только для чтения 2026-10-03T19:05:46.767Z. Для каждого
неархивного места взят последний утверждённый текст, а при его отсутствии
последний черновик. Проверяются первые два предложения и первые 240 символов
вводного абзаца на формы «находится», «расположен/расположена», «располагается»,
«по адресу». Это воспроизводимый широкий отбор, а не полная семантическая оценка.

Все 225 дорожных отрезков OSM relation 2094267 из локального PBF от 22 сентября
собраны в два замкнутых контура. Выбран меньший контур внутренней проезжей части;
точки в пределах 50 м с любой стороны вынесены отдельно. Контур сохранён в
`boundary.geojson`; полоса предназначена для редакторской проверки входов и
маркеров, а не для кадастровых решений.

Wikimapia загружена через существующий клиент с публичным ключом `example`.
Прочитаны 14 подробных карточек и выдачи по 50 соседей для трёх примеров;
сопоставление выполнено вручную. Сырые ответы и полный снимок остаются в
игнорируемом `backend/data/garden-ring-wikimapia/`. В Git сохранены только
публичные поля кандидатов, новые формулировки и ссылки на источники.

## Публикация

Пакет `garden-ring-intros-2026-10-03-v1` применён с проверкой исходных ревизий в
одной транзакции. До записи сделан SQLite-снимок на сервере. Задания озвучки
созданы через действующую очередь, все 14 завершились; API-тексты, квитанции,
доступность MP3 и SHA-256 проверены. Пять фотографий добавлены в полный редакторский
каталог, исходные четыре превью сохранены. [Результаты](../../content/garden-ring-intros-2026-10-03/publication.json)
и [поиск фото](../../content/garden-ring-intros-2026-10-03/photos.md) содержат публичные поля.

Во время работы контейнер генератора был штатно остановлен внешней операцией.
Сервис восстановлен, прерванная аренда задания истекла и очередь завершила пакет
без ручного изменения состояния задания. Перед записью превью каталог повторно
прочитан с сервера; обновления другой редакторской задачи сохранены.

Каталог изображений в контейнере находится на файловой системе только для чтения,
а при старте приложение синхронизирует весь каталог с удалением отсутствующих
редакторских записей. Для сохранности пяти фото собран стандартный серверный образ
с обновлённым JSON. При параллельных публикациях общий build-контекст может быть
перезаписан, поэтому финальная сборка использует отдельный снимок deployed-контекста
и тег `garden-ring-intros-20261003`; файлы JavaScript сверены с работающим сервисом.
Compose запускается с явным `-p otgolosok-generator`, как существующий сервис.

Первый `pnpm check` прошёл lint и typecheck, но Vitest завершился таймаутами
тестов и запуска процессов. Повтор всей JS/TS-выборки с `--maxWorkers=2` и backend
с `--test-concurrency=2` прошёл, затем успешно выполнены Python-проверки и build.

После параллельного обновления статики пять привязок остались в базе, но файлы
новых фото были удалены синхронизацией `dist`. Все десять JPG повторно скопированы
после этого обновления; они сохранены и в `public/images/places` репозитория,
чтобы следующий обычный build включал их. Публичный API требует HTTP/2; запросы
HTTP/1.1 возвращают 505 «Требуется HTTP/2». Для итоговой HTTPS-проверки использован
HTTP/2 с адресом production-узла и проверкой сертификата `otgolosok.online`,
поскольку DNS в рабочем окружении работал нестабильно.

## ElevenLabs для промопрогулок

По уточнению пользователя 4 октября тексты, входящие в промопрогулки, озвучиваются через ElevenLabs. Из 14 изменённых точек в 18 прогулках служебного аккаунта `promo-walks` найден Центральный дом журналиста (`osm:way:46966391`), остановка `boulevard-stop-17` маршрута от Кропоткинской до Тверской.

Штатный `enqueueExternalAudio` с профилем `elevenlabs-v3` и production-нормализатором создал задание `7724c8af-f7a5-4305-85b0-5a562eb5ca63`. Оно успешно завершилось за одну попытку; голос «Отголосок2», длительность 42,384 секунды. Публичный HTTPS API точки и промопрогулки отдаёт новое аудио, скачанный MP3 совпадает по SHA-256 с квитанцией. Текст не менялся; глава с OSM-ссылкой получает актуальное аудио автоматически. Предыдущее F5-аудио сохранено в отчёте публикации.

## Вторая партия: 4 октября

Нижний Александровский сад использован как часть ансамбля, дом Пигита - как контекст музея. Для гостиницы англоязычное OSM-название не дало автоматического совпадения, карточка 336 найдена среди соседей.

Профиль аудио выбирается по свежему списку прогулок аккаунта `promo-walks` непосредственно перед постановкой задания. «Художественный» входит в бульварную промопрогулку и переозвучен через `elevenlabs-v3`. Остальные восемь F5-заданий также успешно завершены; все девять публичных MP3 совпадают с квитанциями. ElevenLabs сначала вернул `TTS_QUOTA_EXCEEDED` для задания `13cf84cc-8f08-4330-85de-cd8cfabd8295`: отдельный лимит ключа «Отголосок прод» составлял 50 000 кредитов, остаток ключа был 86 кредитов при необходимых 509. Баланс аккаунта не был исчерпан. Владелец увеличил лимит ключа, после чего то же задание успешно завершилось. Новый файл `36b565550c88405d8fd80094228482fec44c41cded3df386c1200372c28b869e.mp3` длительностью 62,784 секунды проверен через публичный HTTPS в карточке и главе `boulevard-stop-12`. Production-ключ не имеет права читать или менять список API-ключей (`/user/api-keys` возвращает `needs_authorization`); настройки меняет владелец в Developers → API Keys. После восстановления квоты не следует создавать повторное аудиозадание: для `failed` предусмотрен штатный `retryExternalAudio`, а `retry_wait` обрабатывается автоматически. Во время проверки перед нашим повтором появилась другая очередь ElevenLabs; ожидавшему заданию выставлен приоритет 1, без прерывания текущей аренды. В рабочей shell отсутствовал `SSH_AUTH_SOCK`; подключение с существующим сокетом системного ssh-agent восстановило доступ без чтения закрытых ключей.

Для памятника Чехову добавлен снимок Commons CC BY 2.0. Каталог и два JPG сохранены в репозитории. Образ `garden-ring-batch2-20261004` создан поверх точного работающего image, с заменой только каталога фотографий; перед выкладкой проверено отсутствие параллельной смены image. Исходный каталог стандартного Docker build дополнен одной записью без удаления чужих. Публичная проверка подтвердила все девять текстов, восемь новых аудио, предыдущее аудио кинотеатра и все фотографии.

Проверки с ограниченной параллельностью полностью прошли: lint, typecheck, Vitest 99 файлов / 1099 тестов, backend 747 тестов, Ruff, Pyright, pytest 20 тестов / 15 subtests и build. [Пакет второй партии](../../content/garden-ring-intros-2026-10-04-batch2/README.md) фиксирует девять завершённых правок с новой озвучкой, включая восстановленное задание ElevenLabs.

После параллельной выкладки каталог без фото Чехова снова стал активным. Повторная сборка объединила актуальный production-каталог с новой записью (65 мест), сохранив остальные изображения и текущий серверный код. Два JPG восстановлены в `dist`, публичная проверка повторена с обязательным наличием фото у всех девяти точек. Чтобы исключить такие потери, каталог и статику нужно выкладывать из одного актуального коммита и после выкладки проверять каждый ожидаемый ID и оба JPG; проверка только доступных фотографий пропускает отсутствующие привязки.

Диагностика выполнена штатным повтором и арендой того же аудиозадания, с существующим нормализованным текстом, ElevenLabs v3 и голосом «Отголосок2». Ответ об ошибке прочитан из копии HTTP-ответа; значения переменных с ключами, токенами и секретами удаляются из диагностического сообщения. Проверка подписки с `Accept-Encoding: identity` подтвердила баланс, совпадающий со скриншотом пользователя. Самостоятельного изменения тарифа, покупки кредитов или создания нового ключа не выполнялось.
