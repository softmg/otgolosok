# Подписи городов на проде: Зеленоград, 5–6 октября 2026

## Дефект

73 точки каталога в Зеленограде показывали адрес с городом «Москва»
(например, «КЦ Зеленоград» — «Москва, Центральная площадь, 1»). В OSM у этих
объектов проставлен `addr:city=Зеленоград`, но сборщик каталога
`scripts/import-osm-attractions.py` не включал `addr:city` в `FIELDS`: тег
выбрасывался при импорте, и `osmPostalAddress` подставлял дефолт «Москва».
Исправление — коммит `bfcd6ee` (addr:city сохраняется), поведение закреплено
тестом `79d5398` в `backend/osm-context.test.mjs`.

## Сборка каталога и репетиция

Каталог собран из geofabrik `central-fed-district-latest` (879 МБ, снимок от
04.10, sourceSha256 `cd1dd582…`). Граница Москвы — relation 102269 (v422),
собрана в GeoJSON тем же кодом сборки полигона (`polygon_geometry`); контрольные
точки: Зеленоград/Кремль/Троицк внутри, Химки/Мытищи снаружи. Итог: 6123 объекта
(было 6107: +19, −3, теги изменились у 3565, `addr:city` добавился у 382).

Локальный PBF `backend/data/osm/Moscow.osm.pbf` (bbbike) НЕ содержит Зеленоград
(bbox 55.57–55.92 / 37.32–37.88) — собирать полный каталог только из geofabrik.
Полный импорт с `--complete` на проде БОЛЬШЕ НЕЛЬЗЯ: в базе 12 импортов
(6107 основной + 92 из izi/boulevard-партий), `--complete` заархивирует их.

Репетиция перед продом: снимок прод-базы через `VACUUM INTO` (контейнерный
/tmp — tmpfs 64 МБ, снимок писать в `/data`), импорт без `--complete`,
пересчёт кандидатов — числа совпали один в один (6218 мест, 4322 кандидата,
auto 513 / enrich 2798 / manual 1011, устаревших 0).
