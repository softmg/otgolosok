# Переход из каталога к редактору места

При проверке 22 сентября 2026 года кнопка «Открыть» загружала карточку под всей таблицей из 50 мест, но не перемещала к ней экран. Исправление переводит фокус на заголовок карточки после завершения загрузки; закрытие возвращает к исходной кнопке или заголовку каталога, если строка уже исчезла из выборки.

Регрессионные тесты `src/features/admin/content-admin.test.ts` проверяют открытие текста, повторное открытие, место без текста, возврат к строке, ошибку загрузки и отмену потери несохранённых правок. Для настоящего DOM и проверки фокуса используется jsdom; геометрию прокрутки нужно дополнительно проверять в браузере на production-сборке с длинной таблицей. Локальная браузерная проверка использует тестовые ответы API и не подтверждает доступность production API.

Проверены `pnpm lint`, `pnpm typecheck`, `pnpm test` (204 frontend-теста и 230 backend-тестов) и `pnpm build`. Chromium на экранах 1440×900 и 390×844 подтвердил видимость редактора после открытия, фокус на заголовке, возврат к исходной строке и открытие места без текста; ошибок JavaScript не обнаружено.

В `next dev` при браузерной проверке также наблюдалось зависание на «Восстановление сессии…». В production-сборке с теми же тестовыми ответами оно не воспроизводилось. Вероятная причина: cleanup в `AdminDesk` отменяет запрос при повторном запуске эффектов в Strict Mode, а `sessionRestored` не позволяет начать восстановление заново; это отдельный риск, требующий воспроизводящего теста и корректной отмены/перезапуска загрузки сессии.

При деплое ревизии `9c9e0e8` из чистого `git archive` команда `make check` сначала остановилась на отсутствии `LayoutProps`, затем на несовпадении сгенерированного каталога. Перед повтором потребовались `pnpm exec next typegen` и генераторы каталога/карты из build-скрипта; все проверки после подготовки прошли. Для воспроизводимой проверки чистой копии следует добавить генерацию типов и каталога как зависимости соответствующих Make-целей. Итоги публикации и повторного запуска 126 ошибочных текстовых заданий записаны в [журнале деплоя](../production-runbook.md).
