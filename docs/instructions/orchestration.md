# Оркестрация

## Владеет

Роли, фазы, триаж, попытки, эскалации и возобновление.

## Не владеет

Не определяет условия публикации, валидность кэша, визуальные критерии и пороги допуска.

## ORCH-01

Контентные воркеры меняют только данные выпуска; code_bug с file/symptom/reproduction передаётся координатору для отдельного team-workflow с тестами и независимым ревью. Нельзя вручную чинить движок из контентного шага. Архитектор и Reviewer независимы, Reviewer из другой семьи. Точные команды и схемы результатов задаёт daily-episode.js. Не запускать фоновые LaunchAgent и циклы поллинга; перед редактированием убедиться, что прежний процесс остановлен.

scriptsClean проверяет авторство изменений и привязку к выпуску: правки scripts/*.mjs контентным воркером и хардкод текущей даты запрещены. Параллельные dirty/untracked других задач, не менявшиеся воркером и не содержащие привязки к выпуску, сами по себе scriptsClean не нарушают.

## ORCH-02

За один исправительный проход закрывать весь error.corrections с проверяемыми результатами; остаточные raw-photo/composed-frame направлять visual раньше worker. Соблюдать maxEarlyAttempts. Внутри одного раннего шага разрешено не более двух штатных прогонов preproduction-review. Один дополнительный повтор PREPRODUCTION_CONTRACT/SERVICE без правок файлов разрешён только при установленной инфраструктурной причине и пустых corrections; пустой список сам по себе транзиентность не доказывает. Возобновлять через resumeRunId, выбирая предка без устаревшего проваленного шага.

## ORCH-03

После трёх безрезультатных циклов одного блокера координатор подключает Antigravity agentapi с контекстом только блокера без секретов, проверяя результат штатными проверками; контентные воркеры agentapi не вызывают. Это консультация, не замена независимого ревью или действующего супервизора. Не проводить ручные марафоны исправления карты. Ruflo используется при наличии инструментов; отсутствие интеграции не блокирует работу. Тайм-аут согласования немедленно сообщать в текущий основной тред с действием и следующим шагом; тайм-аут не равен отказу.
