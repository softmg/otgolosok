# Публикация

## Владеет

Разрешения, слоты, очередь, загрузки и readback.

## Не владеет

Не определяет художественную упаковку, звук или качество кадров; использует допуски соседних доменов.

[Реестр доменов](README.md)

## PUB-01

Публикация выполняется только в явно разрешённой задаче. Авторизованный daily-episode с publishScheduled=true публикует исключительно private+publishAt после Final Gate approved и независимого readback; немедленный public запрещён. Durable/build сами по себе полномочий не дают. Слоты считать по Europe/Moscow. Предыдущий выпуск той же московской даты не блокирует новый слот при разнице публикаций строго более 8 часов. Неизвестное состояние очереди (отсутствующая БД, недоступный SSH, устаревший снимок или конфликт форматов) останавливает планирование и не считается пустым слотом.

## PUB-02

При замене сохранять слот: сначала готовая проверенная приватная загрузка, обложка и три дорожки субтитров, затем снять старое расписание и обновить ссылки; прежний ролик остаётся private. Утреннее ожидание готового выпуска не объявлять пропуском: учитывать ротацию и крайнее время. По решению владельца YouTube-выпуск включается в плейлист «Москва», значения настроек «Использование ИИ» и «Прямая реклама» — «нет». YouTube settings и расписание считываются обратно. Обложку назначать после processing succeeded; thumbnails.set=200 не подтверждает публичный значок Shorts, требуется отдельная проверка с ID.
