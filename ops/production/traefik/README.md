# TLS для otgolosok.online

Файлы в этом каталоге — версия настроек TLS и локального middleware `h2only`, установленных на production. С 14 октября 2026 года ALPN объявляет `h2` и `http/1.1`, а `h2only` не подключён ни к одному маршруту: поисковые роботы читают сайт по HTTP/1.1. Общий Traefik обслуживает несколько сайтов, поэтому опция `otgolosok@file` назначена только маршрутам статического сайта и генератора. Перед и после выкладки выполняйте `scripts/verify-production-tls.sh` с `VPS=$VPS (см. .env.ops)`.

На сервере `otgolosok-tls.yml` лежит в `/srv/traefik/`, а `h2only/` — в `/srv/traefik/plugins-local/src/github.com/softmg/h2only/`. В `/srv/traefik/traefik.yml` включены `providers.file.filename: /etc/traefik/otgolosok-tls.yml` и `experimental.localPlugins.h2only.moduleName: github.com/softmg/h2only`. В `/srv/traefik/docker-compose.yml` оба каталога смонтированы только для чтения. Эти два общих файла содержат настройки других сайтов, поэтому при восстановлении добавляйте указанные секции к актуальным файлам, сохраняя остальные настройки. Сначала проверяйте `docker compose config -q`, затем перезапускайте Traefik и запускайте `scripts/verify-production-tls.sh`.

Скрипты выкладки в инфраструктурном каталоге `projects/utils/services` (отдельный Git-репозиторий) сохраняют метку `tls.options=otgolosok@file` для обоих маршрутов и вызывают проверку после деплоя. Копии `otgolosok-tls.yml` и `otgolosok-generator-compose.yml` там должны совпадать с сервером: правку, сделанную только на VPS, следующий деплой откатит. Резервная копия общего Traefik создаётся командой `make -C /Users/fenix007/projects/utils/services backup-traefik VPS=$VPS (см. .env.ops)`.
