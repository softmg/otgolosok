# TLS для otgolosok.online

Файлы в этом каталоге — версия настроек TLS и локального middleware `h2only`, установленных на production. Общий Traefik обслуживает несколько сайтов, поэтому опция `otgolosok@file` назначена только маршрутам статического сайта и генератора. Перед и после выкладки выполняйте `scripts/verify-production-tls.sh` с `VPS=$VPS (см. .env.ops)`.

На сервере `otgolosok-tls.yml` лежит в `/srv/traefik/`, а `h2only/` — в `/srv/traefik/plugins-local/src/github.com/softmg/h2only/`. В `/srv/traefik/traefik.yml` включены `providers.file.filename: /etc/traefik/otgolosok-tls.yml` и `experimental.localPlugins.h2only.moduleName: github.com/softmg/h2only`. В `/srv/traefik/docker-compose.yml` оба каталога смонтированы только для чтения. Эти два общих файла содержат настройки других сайтов, поэтому при восстановлении добавляйте указанные секции к актуальным файлам, сохраняя остальные настройки. Сначала проверяйте `docker compose config -q`, затем перезапускайте Traefik и запускайте `scripts/verify-production-tls.sh`.

Скрипты выкладки в `/Users/fenix007/projects/utils/services` сохраняют метки `tls.options=otgolosok@file` и `middlewares=otgolosok-h2-only@file` для обоих маршрутов и вызывают проверку после деплоя. Они находятся вне Git; при переносе инфраструктуры в репозиторий нужно версионировать и эти скрипты. Резервная копия общего Traefik создаётся командой `make -C /Users/fenix007/projects/utils/services backup-traefik VPS=$VPS (см. .env.ops)`.
